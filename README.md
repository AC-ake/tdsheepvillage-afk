## 第一次运行

1. 保持 `羊村挂机助手.py`、`requirements.txt` 与 `templates` 文件夹在同一目录。
2. 安装 Python 3.10 或更新版本。
3. 在此目录运行：`pip install -r requirements.txt`。
4. 运行：`python 羊村挂机助手.py`。


程序也会创建 `图像` 文件夹。该文件夹中同名的 PNG 会优先于内置模板，用于玩家替换识图图片。

## 使用要点

- 游戏请使用 **1080P、100% 缩放**。
- `F8` 是全局急停。
- 可勾选“窗口置顶”，让工具窗口在点击游戏时仍显示在最前方。
- 塔坐标仅用于本次脚本启动，不会保存；点“开始录入”后，鼠标移到塔上按 `K` 添加，按 `ESC` 结束。
- 两种战斗模式只能选一个；自动升塔可与任一战斗模式并行。
- 敲狼坐标和参数只会在点击“保存配置”后保存。
- 识图敲狼识别到后才会在范围内随机点击，未识别到则直接翻到下一位好友。

## 可以放心调整的内容

界面中出现的阈值、等待时间、循环间隔、敲狼随机范围和点击次数都可以调整。若手动修改 `羊村挂机配置.json`，也只会修改这些数值及两项敲狼坐标。

请不要修改 Python 文件中的线程、急停、模板文件名或配置字段名称；这些内容会影响程序运行逻辑。

## 自定义图片的严格命名

请只放入 PNG 图片，并严格使用下列名称：

- 升塔：`shengji.png`、`liliang.png`、`jiahao.png`、`tacha`
- 自动攻击：`gongji.png`
- Boss / 驱赶：`boss.png`、`4boss.png`、`yiban.png`、`putong.png`、`kunnan.png`、`qugan.png`、`bosscha.png`、`cha.png`
- 识图敲狼：`jiandielang.png`
- 确定：`queding.png`

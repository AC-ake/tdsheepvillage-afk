## 第一次运行

1. 保持 `羊村挂机助手.py`、`requirements.txt` 与 `templates` 文件夹在同一目录。
2. 安装 Python 3.10 或更新版本。
3. 在此目录运行：`pip install -r requirements.txt`。
4. 运行：`python 羊村挂机助手.py`。


程序也会创建 `图像` 文件夹。该文件夹中同名的 PNG 会优先于内置模板，用于玩家替换识图图片。

## 使用要点

- 游戏请使用 **1080P、100% 缩放**。
- `F8` 是全局急停。
- `F12` 开关运行日志（默认关闭）。按 `F12`，或点启动页「停止全部 / F8」右边的「记录日志 F12」按钮都可以；
  开启后每次运行会在 `logs` 文件夹里生成一个按启动时间命名的 txt（例如 `2026-09-19_21-32-55.txt`），
  界面日志框里的内容会同步写进文件，用来排查问题和调参。关闭时界面照常显示日志，只是不写文件。
- 可勾选“窗口置顶”，让工具窗口在点击游戏时仍显示在最前方。
- 塔坐标仅用于本次脚本启动，不会保存；点“开始录入”后，鼠标移到塔上按 `K` 添加，按 `ESC` 结束。
- 两种战斗模式只能选一个；自动升塔可与任一战斗模式并行。
- 敲狼坐标和参数只会在点击“保存配置”后保存。
- 识图敲狼识别到后才会在范围内随机点击，未识别到则直接翻到下一位好友。
- 敲狼时会先加速好友矿产：识别到 `jiasu.png` 才点击，等 1 秒后点确定，再继续间谍狼流程。
  加速到第 5 次会连着弹出两个确定框，脚本会自动连点确定（次数可在敲狼页调整），点确定后的等待也会正常生效。
- 定时重开游戏（测试中）：在“定时重开”页设好时间（默认 `00:01`）并勾选后，到点会自动重开游戏并走
  重开 → 领奖 → 翻牌 → 进入 → 前线的流程。点 `qianxian.png` 之前会先停掉正在运行的功能，
  之后自动恢复**当时开启**的功能（原本关着的保持关闭）。整段流程限制在设定总时长内（默认 61 秒，且同一分钟只会触发一次），
  某一步卡住会重新从 `bwyc.png` 开始，`F8` 可随时中止。

## 可以放心调整的内容

界面中出现的阈值、等待时间、循环间隔、敲狼随机范围和点击次数都可以调整。若手动修改 `羊村挂机配置.json`，也只会修改这些数值及两项敲狼坐标。

请不要修改 Python 文件中的线程、急停、模板文件名或配置字段名称；这些内容会影响程序运行逻辑。
